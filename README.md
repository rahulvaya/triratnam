# Triratnam Elite Stay — Promotional Website

A modern, responsive single-page website for promoting Triratnam Elite Stay apartments in Sector 4, Hiran Magri, Udaipur.

## Files

- `index.html` — main page
- `styles.css` — styling
- `script.js` — gallery lightbox, WhatsApp enquiry form, scroll animations
- `images/` — drop your photos here (see required filenames below)

## Run locally

Just open `index.html` in your browser. No build step.

## Publish to GitHub Pages

1. Create a new GitHub repo, e.g. `triratnam-elite-stay`.
2. Push this folder's contents to the repo root.
3. In **Settings → Pages**, set Source = `main` branch / `root`.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
